# Crypto Market Dashboard 💰

A modern and responsive cryptocurrency market dashboard built using HTML, CSS, and JavaScript.

The project uses a cryptocurrency API to fetch and display current market prices for popular cryptocurrencies such as Bitcoin, Ethereum, and Dogecoin.

## 🚀 Features

- 📊 Real-time cryptocurrency price data
- ₿ Bitcoin price display
- Ξ Ethereum price display
- 🐕 Dogecoin price display
- 🔌 API integration for fetching live data
- 📱 Responsive design
- 🎨 Modern dark-themed UI
- ⚡ Dynamic data rendering using JavaScript
- 🖱️ Interactive navigation and buttons

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Cryptocurrency API

## 🎯 Purpose

This project was created to practice:

- Working with APIs
- Fetching external data using JavaScript
- Handling JSON responses
- DOM manipulation
- Responsive web design
- Building a modern frontend interface
